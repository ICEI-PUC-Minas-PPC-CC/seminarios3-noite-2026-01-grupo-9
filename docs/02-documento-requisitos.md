# 02 — Documento de Requisitos do Software

> **Grupo:** *Grupo 9 *   
> **Aplicação:** *Transcrição de fala em tempo real para lingua de sinais (Libras) e em texto.*  
> **Comunidade:** *Deficientes auditivos.*

---

## 1. Visão Geral

Um software que traduz audio para lingua de sinais (Libras) e e gera em texto na tela instataneamnete, destinada a deficientes auditivos, podendo facilitar a comunicação entre leigos em libras e deficientes auditivos.
## 2. Público-Alvo

| Campo | Informação |
| ------- | ----------- |
| Perfil dos usuários | Deficiente Auditivo |
| Faixa etária | A partir dos 8 anos |
| Necessidades de acessibilidade | Ter um celular ou computador |
| Nível de familiaridade com tecnologia | Básico |

> **Lembrete (Tarso de Coimbra):** Os usuários podem ter deficiência auditiva/surdez. A interface deve ser **visual, intuitiva e de baixa complexidade**. Priorize elementos visuais (imagens, ícones, cores) sobre texto extenso.
